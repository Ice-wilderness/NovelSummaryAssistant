## Purpose
Define the chapter split preview API and confirmation workflow before writing split chapter files.

## Requirements
### Requirement: 分割预览 API
系统 SHALL 提供后端 API 端点，接收源文件内容和分割参数，返回分割后的章节数量和每章名称列表，但不写入任何文件。

#### Scenario: 默认模式预览成功
- **WHEN** 用户上传源文件并请求默认模式预览
- **THEN** 系统返回分割后的章节总数和每章的标题（按顺序），包含每章的起始行号

#### Scenario: 正则模式预览成功
- **WHEN** 用户选择一个正则配置并请求预览
- **THEN** 系统使用该配置的模式字符串构建正则，扫描源文件内容，返回匹配到的章节列表

#### Scenario: 标题列表模式预览成功
- **WHEN** 用户提供标题列表并请求预览
- **THEN** 系统按标题列表顺序匹配源文件内容，返回匹配到的章节列表，标注未匹配到的标题

#### Scenario: 预览未匹配到任何章节
- **WHEN** 源文件内容与选定的分割模式不匹配（例如正则无法命中任何行）
- **THEN** 系统返回明确错误，建议用户检查分割模式

#### Scenario: 大文件预览
- **WHEN** 源文件内容超过 5MB
- **THEN** 系统仍然执行预览扫描，前端显示加载指示器

### Requirement: 预览与实际分割共享章节边界
分割预览 API SHALL 使用与实际分割写文件相同的章节边界解析结果，确保用户确认分割后生成的章节顺序、标题和数量与预览一致。

#### Scenario: 默认模式预览和实际分割一致
- **WHEN** 用户使用默认模式请求预览并随后确认分割同一份源文本
- **THEN** 预览返回的章节数量和标题顺序 MUST 与实际写出的章节文件数量和标题顺序一致

#### Scenario: 正则模式预览和实际分割一致
- **WHEN** 用户使用通过安全校验的正则配置请求预览并随后确认分割同一份源文本
- **THEN** 预览返回的章节边界 MUST 与实际分割使用的章节边界一致

#### Scenario: 标题列表模式预览和实际分割一致
- **WHEN** 用户使用标题列表模式请求预览并随后确认分割同一份源文本
- **THEN** 系统 MUST 使用同一标题匹配结果生成预览项和章节文件

### Requirement: 分割预览返回可操作错误
分割预览 API SHALL 在章节边界解析失败时返回用户可理解的错误，而不是返回空列表冒充成功。

#### Scenario: raw 正则预览被安全校验拒绝
- **WHEN** 用户选择的 raw 正则为空、语法无效、过长、明显高风险或预检失败
- **THEN** 预览 API MUST 返回 400 错误，并在 detail 中说明拒绝原因

#### Scenario: 预览未匹配到章节
- **WHEN** 源文件内容与选定的分割模式不匹配
- **THEN** 预览 API MUST 返回明确错误，提示用户检查分割模式或标题列表

### Requirement: 前端预览展示
分割前的预览信息 SHALL 以清晰、可滚动的方式展示给用户，包含章节总数和名称列表。

#### Scenario: 预览面板显示
- **WHEN** 预览结果返回
- **THEN** 页面显示一个预览面板，顶部醒目展示章节总数，下方为可滚动的章节名称列表（含序号和标题文字）

#### Scenario: 预览后用户确认分割
- **WHEN** 用户查看预览结果后点击"确认分割"
- **THEN** 系统执行实际的文件分割操作

#### Scenario: 预览后用户取消或调整
- **WHEN** 用户查看预览结果后认为结果不对，调整分割模式后重新预览
- **THEN** 系统使用新的参数重新执行预览，替换面板中的结果

#### Scenario: 小说总结入口预览确认后的行为
- **WHEN** 用户在小说总结页面的分割预览面板点击"确认分割"
- **THEN** 系统执行分割并直接将结果章节写入项目，更新项目章节列表，源文件从源文件区域移除
