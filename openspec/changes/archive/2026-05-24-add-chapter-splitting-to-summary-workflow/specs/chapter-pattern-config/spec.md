## ADDED Requirements

### Requirement: 正则配置存储完整正则表达式
每个正则配置 SHALL 存储一份完整的、可直接编译的正则表达式字符串，并标注其模式类型（`raw` 完整正则 或 `simple` 占位符模式），系统根据模式类型决定是直接编译还是通过构建器转换后编译。

#### Scenario: raw 模式配置 — 使用完整正则
- **WHEN** 用户创建一个 `raw` 模式的配置，并直接输入完整正则表达式（如包含零宽断言、多分支、Unicode 字符类的复杂正则）
- **THEN** 系统存储该正则原样，分割时直接编译并用于匹配，不进行占位符替换

#### Scenario: simple 模式配置 — 使用占位符语法
- **WHEN** 用户创建一个 `simple` 模式的配置，输入 `第n章` 风格的占位符模式
- **THEN** 系统存储该占位符字符串，分割时按现有 `regex_strategy.py` 逻辑自动构建正则（将 `n` 替换为数字匹配模式、转义前后缀）

#### Scenario: raw 模式正则不含捕获组时自动包裹
- **WHEN** 用户提供的 `raw` 正则不含捕获组（例如纯匹配式 `(?<=[　\s])(?:序章|楔子|第[\d]+章).{0,50}$`）
- **THEN** 系统自动将其包裹为 `^\s*(({regex}).*)` 以生成符合 `process_chapters_with_regex` 要求的 group(1) 和 group(2)

#### Scenario: raw 模式正则已含捕获组时直接使用
- **WHEN** 用户提供的 `raw` 正则已包含正确的捕获组定义
- **THEN** 系统直接编译使用，不额外包裹

### Requirement: 预设默认正则配置
系统 SHALL 出厂预置若干默认正则配置，涵盖常见的小说章节标题格式，用户可直接选用或在此基础上修改。

#### Scenario: 默认配置列表
- **WHEN** 应用首次启动或 `chapter_patterns.json` 不存在
- **THEN** 系统自动创建默认配置，至少包含：
  - `默认-第X章`（当前 default_strategy.py 的内置正则：`第\s*[一二三四五六七八九十百千万亿零\d]+\s*(?:章|节|回)`）
  - 系统保留后续通过导入方式扩充预设配置的能力

#### Scenario: 默认配置可编辑但不可删除
- **WHEN** 用户选中一个系统预设的默认配置
- **THEN** 用户可以编辑（另存为副本）和切换使用，但原始预设不可删除

### Requirement: 正则配置的 CRUD 管理
系统 SHALL 支持用户创建、编辑、删除、切换章节分割的正则配置，每个配置包含名称、正则表达式、模式类型、描述等字段。

#### Scenario: 创建新配置
- **WHEN** 用户打开正则配置管理器并点击"新建配置"
- **THEN** 系统创建一个新配置项，默认模式为 `raw`，用户可编辑名称、正则表达式和描述

#### Scenario: 编辑已有配置
- **WHEN** 用户选择已有配置并修改其名称、正则或描述后保存
- **THEN** 系统更新该配置并持久化到 `chapter_patterns.json`

#### Scenario: 删除自定义配置
- **WHEN** 用户删除一个非系统预设的配置
- **THEN** 系统从存储中移除该配置，并从配置列表刷新

#### Scenario: 切换当前使用的配置
- **WHEN** 用户在配置列表中选择一个配置作为当前使用的正则模式
- **THEN** 分割操作使用该配置的正则表达式，切换立即生效

### Requirement: 正则配置的导入/导出
系统 SHALL 支持用户将正则配置导出为 JSON 文件，以及从 JSON 文件导入配置。

#### Scenario: 导出单个配置
- **WHEN** 用户在配置管理器中点击某个配置的"导出"按钮
- **THEN** 系统生成一个包含该配置完整信息（含 regex_mode、pattern、name、description）的 JSON 文件并触发浏览器下载

#### Scenario: 导入配置
- **WHEN** 用户点击"导入"按钮并选择一个有效的正则配置 JSON 文件
- **THEN** 系统解析文件内容，将其中配置追加到当前配置列表（重名时提示覆盖或跳过）

#### Scenario: 导入文件格式无效
- **WHEN** 用户选择的 JSON 文件格式不符合正则配置规范
- **THEN** 系统显示格式错误提示，不修改当前配置列表

### Requirement: 配置在分割页面中的使用
章节分割页面和小说总结页面的分割区域 SHALL 使用正则配置管理器提供的配置，替代当前的自由文本 textarea。

#### Scenario: 分割页面选择正则模式
- **WHEN** 用户在分割页面选择"正则"模式
- **THEN** 页面显示配置选择下拉列表和正则预览文本，用户可选择已有配置或点击进入配置管理器

#### Scenario: 用户可直接编辑当前选中配置的正则
- **WHEN** 用户在分割页面选中一个配置后，在正则文本区域直接修改正则表达式
- **THEN** 修改自动保存到该配置，下次切换回来时保留修改

### Requirement: 配置持久化
正则配置 SHALL 持久化到应用根目录的 `chapter_patterns.json` 文件中，随应用启动加载。

#### Scenario: 应用重启后配置保留
- **WHEN** 用户创建并保存多个正则配置后重启应用
- **THEN** 所有配置仍然可用，上次选择的配置保持选中状态
