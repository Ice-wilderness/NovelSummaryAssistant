# Studio WebUI 功能映射

本文件记录 `modernize-studio-webui` 实施前的功能盘点，避免“写作工作室”重构只复刻 demo 或遗漏真实能力。

## 全局工作台

| 现有能力 | Studio 区域 | 实施备注 |
| --- | --- | --- |
| 主导航：小说、文章、自定义、章节分割、雷点扫描、提示词、API 配置 | 左侧 Studio navigation | 保留 `activeView` 状态切换，不丢失各页本地草稿 |
| 当前任务状态、暂停、恢复、取消 | 顶部 task strip | 继续使用 `useTaskAvailability` 和任务控制 API |
| 全局错误和系统提示 | 顶部/当前上下文附近 | 错误仍可关闭，配置加载和终态信息必须可见 |
| 全局/API 日志 | 底部或右下 Studio feedback surface | 保留全局/API 来源切换、长日志展开、清除日志 |
| 项目署名 | 左侧底部或关于区域 | 保留原作者和现作者信息 |

## 小说总结

| 现有能力 | Studio 区域 | 实施备注 |
| --- | --- | --- |
| 历史项目、新建、恢复、删除、导入旧项目 | 左侧项目/章节 context rail | 项目名、状态、更新时间需要可扫读 |
| 项目保存、项目草稿 | 当前步骤 inspector | 保存项目和任务启动前自动保存保持原语义 |
| 源 TXT 上传、分割模式、正则/标题列表、分卷、预览、确认导入 | 中央 manuscript canvas | 作为上传到章节预览的一条流程呈现 |
| 已分割章节上传/移除/清空 | 中央章节列表或左侧章节胶片 | 保留上传限制、缺失文件显示和移除行为 |
| 输出目录浏览、打开、验证、默认回退 | 当前项目上下文/inspector | 错误必须靠近输出目录控件 |
| API 选择、最终总结 API | 任务配方面板 | 保留全局启用 API 的二级筛选逻辑 |
| 批量、阈值、输出格式、精细流程、字数设置 | 任务配方面板 | 可以折叠/分组，但不可隐藏关键含义 |
| 阶段进度、项目进度、修复建议 | 中央阶段流和 inspector | 修复动作仍需 LLM/内容变化/覆盖确认 |
| 仅小总结、开始总结 | 顶部主操作和当前步骤 | disabled 条件保持原逻辑 |

## 文章总结与自定义总结

| 现有能力 | Studio 区域 | 实施备注 |
| --- | --- | --- |
| 项目历史、导入、保存、上传、输出目录、项目进度 | 项目 context rail + 当前步骤 | 与小说项目使用同一托管项目模式 |
| 文章总结字数设置 | 任务配方面板 | 保留段落总结和最终总结配置 |
| 自定义总结 API、用户指令、结果显示 | 中央编辑区 + inspector | 自定义指令是核心输入，需保持显眼 |
| partial_failed 提示 | 当前结果/警告区域 | 保留可用产物和失败详情说明 |

## 章节分割

| 现有能力 | Studio 区域 | 实施备注 |
| --- | --- | --- |
| 源文件选择、拖拽、编码读取 | 中央 manuscript upload | 工具型页面，不创建托管项目 |
| 默认/正则/标题列表模式、分卷处理 | 当前步骤 inspector | 规则选择靠近预览操作 |
| 预览分割、确认分割 | 中央预览区 | 预览结果仍使用 `SplitPreviewPanel` 或等价展示 |
| 输出目录选择和错误 | 当前步骤 inspector | 保持 local picker 错误提示 |

## 雷点扫描

| 现有能力 | Studio 区域 | 实施备注 |
| --- | --- | --- |
| 档案管理：创建、复制、删除、导入、导出、分组、规则、展开折叠、保存 | 左侧/中央 profile studio | dirty 状态和后端校验必须保留 |
| 扫描配置：项目、档案、范围、API、验证、阈值、批量、续扫、预检、保存、启动 | 当前步骤 inspector | 预检结果必须清楚引导下一步 |
| live findings、stage progress、任务控制 | 中央扫描状态 + 顶部 task strip | 保留运行中反馈 |
| 报告历史、报告详情、事件/发现视图、过滤、分页、剧透、复核、备注、上下文、导出、删除 | 中央 report review canvas | 重点优化审阅舒适度，不减少表格/过滤能力 |
| unverified、partial_failed、legacy-compatible 等警告 | 报告摘要附近 | 不可被装饰性布局稀释 |

## 提示词与 API 配置

| 现有能力 | Studio 区域 | 实施备注 |
| --- | --- | --- |
| 工作流 tabs、节点列表、消息编辑、模块引用、模块管理、保存/重置 | 中央 editor canvas + inspector | 保留模块引用说明和 unsaved 状态 |
| API 配置增删改、Key 显示、模型拉取、全局启用、用户默认导出目录、恢复警告 | 中央 config canvas + inspector | 保留敏感输入和恢复警告的明确性 |

## 验收检查

- 每个旧页面迁移前后都要对照本映射检查功能入口。
- 任务状态、日志、警告、错误、修复确认和 partial result 信息优先级高于装饰效果。
- PC 宽屏为主要验收目标；窄宽只需确保关键内容可达。
